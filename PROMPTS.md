# Prompt Engineering Log

This document records the AI prompts and instructions used to generate the architecture, documentation, and codebase for Worry Box.

## Initial Concept Prompt
> "Act as a product manager and clinical psychologist. I want to build an app called 'Worry Box'. The idea is that anxious people can type a worry into the app, and the app visually locks it away in a box. The box cannot be opened until a scheduled time later in the day. Outline the psychological basis for this, the core user flow, and the minimum viable features needed for a web prototype."

## Documentation Generation Prompt
> "Act as a professional AI and prompt engineer and create all the necessary markdown documentation files for this project in detail. Include README, PROJECT_OVERVIEW, REQUIREMENTS, ARCHITECTURE, TECH_STACK, DATABASE, API_SPEC, UI_UX, CODING_STANDARDS, SECURITY, TESTING, DEPLOYMENT, ROADMAP, CHANGELOG, BUGS, and PROMPTS. Add all those to the repo."

## Design Prompt (For UI Generation)
> "Act as a senior UX/UI designer. I am building the Worry Box app in vanilla HTML/CSS. Give me a modern, premium design system. Use smooth gradients, glassmorphism, and a calming aesthetic. Provide the CSS variables for the color palette, typography recommendations, and keyframe animations for the 'lock' and 'release' interactions."
