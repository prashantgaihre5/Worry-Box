# Worry Box

Worry Box is a digital mental health tool designed to help people manage anxious and intrusive thoughts using a clinically recognized Cognitive Behavioral Therapy (CBT) technique known as "scheduled worry time."

## Concept

Instead of trying to suppress worries (which often backfires), Worry Box allows you to "put them away" in a secure digital container. These worries are locked until a predetermined time, delaying engagement and reducing their immediate urgency.

## Getting Started

1. Clone this repository.
2. Run `npm install` (if using Vite setup).
3. Run `npm run dev` to start the local development server.
4. Open the app in your browser and start logging your thoughts.
