# Roadmap

## Phase 1: MVP (Current)
- Core interaction loop (Input -> Lock -> Reveal).
- Basic CSS animations.
- LocalStorage integration.
- Responsive design.

## Phase 2: Polish & Customization
- Customizable unlock times (e.g., user selects 8 PM).
- Multiple box themes/visuals.
- Sound effects (subtle lock clicks, release chimes).
- PWA Support (Installable on mobile home screens).

## Phase 3: Analytics & History
- "Worry Log" - a calendar view of past worries that were kept.
- Basic local statistics (e.g., "You let go of 80% of your worries this week").
- Data export/import (JSON) to allow users to backup their data manually without a backend.
