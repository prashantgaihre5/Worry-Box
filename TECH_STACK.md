# Tech Stack

This project deliberately avoids heavy frameworks to maintain simplicity, performance, and long-term maintainability.

## Core Technologies
- **HTML5:** Semantic markup.
- **CSS3:** Vanilla CSS, CSS Variables, Flexbox/Grid, and CSS Animations (Keyframes, Transitions).
- **JavaScript (ES6+):** Vanilla JS for DOM manipulation and state logic.

## Tooling & Build
- **Vite:** Used as the build tool and development server for fast HMR (Hot Module Replacement) and easy bundling.
- **npm:** Package manager for any necessary dev dependencies (e.g., ESLint, Prettier).

## Storage
- **Window.localStorage:** Used for all data persistence. No external databases.
