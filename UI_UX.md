# UI & UX Guidelines

## Design Philosophy
The design must evoke calm, safety, and release. It should not feel like a typical productivity tool or a clinical medical app. 

## Aesthetics
- **Colors:** Deep, soothing tones (dark blues, muted purples, soft greens) combined with glassmorphism to create depth.
- **Typography:** Modern, clean sans-serif (e.g., *Inter*, *Outfit*, or *SF Pro*). High legibility is critical.
- **Gradients:** Soft, animated mesh gradients in the background to simulate breathing or calmness.

## Core Interactions
1. **The Drop:** When a worry is submitted, it should visually "fall" or be sucked into the box element.
2. **The Seal:** A heavy, satisfying "lock" animation (a lid closing, a padlock snapping) reinforces that the thought is secure.
3. **The Wait:** The locked screen should be minimalist, showing only a subtle countdown or a calm message ("Your thoughts are safe. See you at 6 PM.").
4. **The Release:** Unlocking should feel airy and light. When a user "lets go" of a worry, it should dissolve or float away smoothly.
